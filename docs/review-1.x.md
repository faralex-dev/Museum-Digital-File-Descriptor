# Обзор кода версии 1.0.1

Проверка перед переписыванием (сентябрь 2026). Все пункты исправлены в 2.0.

## Критичные

1. **Для текстового документа `.txt` программа затирала сам документ.** Файл
   контрольных сумм назывался `<имя>.txt` и лежал рядом с оригиналом, поэтому
   для `notes.txt` содержимое документа заменялось хешами. Воспроизведено.
2. **Файлы с одинаковым именем затирали описания друг друга**
   (`photo.jpg` и `photo.tif` → один `photo.xml`, `photo.txt`).
3. **Ошибка хеширования записывалась в XML вместо суммы**
   (`***** error: … ******`), при этом программа сообщала «Успешно».
4. **На Python 3.10–3.11 программа не запускалась:** f-строка с кавычками того
   же типа внутри (`xml_generator.py`, строка 479) — `SyntaxError` до 3.12.
5. **Пути склеивались через `'\\'`** — на macOS и Linux файлы писались не туда.
6. **При перетаскивании второго файла** его описание записывалось в XML первого:
   путь сохранения не обновлялся.
7. **`requirements.txt` назывался ` requirements.txt`** (с пробелом),
   команда из README не работала.

## Серьёзные

8. Ошибка отступа при записи высоты изображения: значение перезаписывало
   чужой элемент или приводило к `UnboundLocalError`.
9. В режиме папки пропускались все `.txt`, хотя это поддерживаемый формат;
   сравнение расширений было чувствительно к регистру.
10. «Успешно» показывалось и после ошибки; при ошибках в папке — окно на каждый файл.
11. Поле «Путь сохранения» в режиме папки ни на что не влияло.
12. Вся работа шла в потоке интерфейса — окно «не отвечало» на больших файлах;
    прогресс хеширования (`tqdm`) выводился в консоль, которой нет в `.exe`.
13. Тег `Сommon` начинался с кириллической «С».
14. Изображения целиком загружались в память через ImageMagick.
15. Падения на нестандартных медиафайлах (`value[4]` у длительности,
    `metadata["file_format_general"]`); размер кадра перезаписывался размером обложки.

## Мелкие

* Битрейт видео ниже 330 кбит/с округлялся до «стандартного» аудиозначения.
* «Количество букв» считало все символы.
* Формат писался то с точкой (`.jpg`), то без (`mp4`).
* Переменная с SHA-1 называлась `file_checksum_sha256`.
* PyPDF2 устарел, зашифрованные PDF не обрабатывались.
* Лишние зависимости (`python-pptx`, `cryptography`), жёстко заданные
  `GMIG` и топография, версия в заголовке `1.0.0` при теге `1.0.1`,
  опечатка «Пусть сохранения», тестов не было.
