# История изменений

## 2.0.0 — 2026-09

Программа переписана. Формат описания изменён — см. [docs/format-2.0.md](docs/format-2.0.md).

### Новое
- Единица хранения по главе 33 правил: один предмет — одна папка, в ней
  мастер-копии (можно несколько, можно в подпапках), XML и файл контрольных сумм.
- Три режима: папка — один предмет; каждая подпапка — отдельный предмет;
  каждый файл — отдельный предмет.
- Сведения о предмете: учётный номер (по умолчанию из имени папки до «_»),
  наименование, описание, топография, носитель, сведения о нормализации.
- Контрольные суммы SHA-1 (как в КАМИС) и ГОСТ 34.11-2018 за один проход по файлу.
  SHA-256 в новых описаниях не используется, но при сверке распознаётся.
- **Сверка** (пп. 33.5–33.8): пересчёт сумм, проверка открытия файлов,
  поиск отсутствующих и лишних файлов, проверка резервной копии, отчёт
  (текст или CSV) и дата для поля «Сверка» в КАМИС. Понимает описания версии 1.x.
- Идентификаторы форматов PRONOM и замечания о пригодности формата для
  длительного хранения (п. 33.10).
- Сводная таблица CSV для КАМИС по всем описанным предметам.
- Версия программы и формата записывается в XML.
- Командная строка: `mdfd describe`, `mdfd verify`, `mdfd info`.
- Тесты, сборка для Windows и macOS через GitHub Actions.

### Меньше внешних зависимостей
- Хеш ГОСТ — собственная реализация на C внутри программы (сверена с
  контрольными примерами стандарта и с pystribog); сборка pystribog и
  Microsoft C++ Build Tools больше не нужны.
- ImageMagick заменён на Pillow; MediaInfo входит в пакет pymediainfo.
- Кодировка текста определяется без chardet, DOCX/ODT/RTF разбираются без
  python-docx, odfpy и striprtf; ttkthemes и tqdm больше не нужны.

### Исправлено
- Все ошибки из [обзора кода 1.x](docs/review-1.x.md), в том числе затирание
  исходного `.txt` и совпадение имён описаний.
- Окно не зависает при обработке больших файлов, работу можно отменить.
- Перезапись существующего описания отменяется, если файлы мастер-копии
  изменились с прошлого раза.
